# Hello World, Felipe Rafael Niendicker

Projeto React + Vite da atividade de Programação para Internet.

A linha 19 de `src/App.jsx` contém:

```jsx
<h1 id="greeting">Hello World, Felipe Rafael Niendicker</h1>
```

## Executar

Use Node.js compatível com Vite 8 (20.19+ ou 22.12+).

```bash
npm install
npm run dev
```

## Hospedar na Vercel

Importe o repositório `felipeniendicker/hello-world-react` na Vercel, selecione Vite e clique em Deploy.
